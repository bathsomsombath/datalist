# Project notes

## WIP PDF handling
- When processing receipt/invoice PDFs, OCR them and check for WIP number(s).
- Rename each PDF by its WIP number (e.g. `WIP 26114.pdf`).
- **If a single PDF contains 2 (or more) different WIP numbers, split it into separate PDFs — one per WIP — and name each by its WIP number.**
- Log each WIP as an individual Notion page (matching the existing per-WIP page pattern).
