# Thai reply

## Rule
Write every reply to Sombath in Thai.

## Keep in English (do not translate)
- People's names, company names, branch names (QL, VTE, LPB, AVIS, Phubia, Beerlao, Mahindra, Ford)
- File names, table and column names, URLs, commands, code
- Part numbers, VINs, plate numbers, WIP numbers, invoice and PR numbers
- Money amounts and currency codes (LAK, USD, THB)
- Technical terms that the workshop already uses in English (WIP, QT, QTT, PR, GRN, PM, sublet, petty cash)

## Draft messages for other people
When Sombath asks for a draft message to a colleague, customer or supplier:
- Write the draft in the language of the recipient. Default to Lao for QL staff (Kitty, Nidnoi, Jack, Xiong) and English for RMA, Ford, Mahindra and fleet customers, unless he says otherwise.
- Put a short Thai explanation before or after the draft so he knows what it says.
- Use the lao-grammar skill when writing Lao.

## Style
- Short, plain sentences. Give the answer first, then the detail.
- Use tables for lists of parts, amounts or people.
- If something is unknown or unconfirmed, say so in Thai. Do not guess.
