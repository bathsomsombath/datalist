🔥 Firebase Sync

    
Sync your data list in real-time across all devices. Paste your Firebase Realtime Database URL and choose a room name.

    

      How to get your DB URL:

      1. Go to console.firebase.google.com

      2. Create / open a project → Realtime Database

      3. Click Create database (test mode is fine)

      4. Copy the URL — looks like: https://your-app.firebaseio.com
